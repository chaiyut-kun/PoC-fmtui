Protocol 1

Session Directory Sync

Uses atomic file signaling (`/tmp/fmtui-dir`) to communicate navigation state back to parent shells, allowing `cd on exit` without shell sub-process hacks.

Protocol 2

Clean Tool Suspension

Surrenders and re-acquires the terminal TTY cleanly, enabling seamless transitions to full-screen interactive tools like Neovim, Emacs, or Bash.

Protocol 3

Telemetry Streaming

Long-running background tasks emit incremental progress metrics through decoupled events, giving real-time feedback with responsive cancellation.
