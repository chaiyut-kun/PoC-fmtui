01 · System Architecture (Conceptual)

Layered Subsystem Architecture

A clear four-tier separation of concerns: Presentation, Application & Orchestration, Domain Services, and Infrastructure Integration with the host environment.

Tier 1

Presentation

Pure UI rendering and layout calculations. Maintains responsive multi-column geometry without performing any direct filesystem mutations.

Tier 2

Application

Dispatches keyboard and mouse events, coordinates multiple tab sessions, and oversees background worker goroutines and cancellation tokens.

Tier 3

Domain Services

Core business logic: reversible file operations, soft deletion to Trash, real-time in-memory filtering, and deep path discovery algorithms.

Tier 4

Infrastructure

Platform gateways: POSIX file system syscalls, system clipboard integration, seamless terminal handover to external editors, and shell state sync.
